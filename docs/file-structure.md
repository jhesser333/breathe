# File structure

_Moved out of CLAUDE.md on 2026-11-10. Detail reference: read when working on this area._

## File structure
```
src/
  App.jsx                   — screen routing (selectMode [home, initial state]/sliderLayouts/personalize/breathPaceOptions/shape, else falls through to the experience screen — including the `'experience'` string set by Breath Pace Options' Home button), shape/sliderLayout/targetPace/selectedMode state (shapeOption defaults to `'d'` for first-time users, see localStorage init; whitelist is `['a'…'j']`; targetPace defaults to `DEFAULT_TARGET_PACE` from `breathPace.js`, whitelist is `Object.keys(TARGET_PACES)`; selectedMode defaults to `'tutorial'`, whitelist `['tutorial','timed','slowing','box']`, passed to SelectModeScreen as selectedMode/onSelectModeChange so the last-chosen mode card survives navigating away and back), tutorial logic, localStorage; palette is locked to `PALETTES.teal` (no colorPalette state, no picker; `PALETTES.a`/`PALETTES.b` remain defined but unreachable); camera is per-shape via the `CAMERA_BY_SHAPE` map (module-level constant, keyed by `shapeOption`, see Current scene setup → Camera); tutorial architecture uses pendingGatesFnRef (function thunk) for mode-specific Text C; key refs: recordingEnabledRef, lastMaxTimeRef, gateEnableTimerRef, inhaleSecondsRef/exhaleSecondsRef (both null except during Slowing Down's ramp — reset unconditionally in handleSelectMode and resetSlowingState — read by Gates*/BackgroundA/BackgroundB), shapeRef, bbCycleRef, bbTutorialActiveRef, breathPhaseRef (owned here, written by gate files on Z=0 crossings, read by BackgroundA/BackgroundB), holdFlareRef (owned here, written by GatesBoxBreathingHeadlessE, read by StarFieldE); backgroundOption is a derived constant (not stored state): `shapeOption === 'e' ? 'b' : shapeOption === 'd' ? 'a' : 'none'`; targetPaceInfo derived from `TARGET_PACES[targetPace]`, passed to SlowingDownController as targetInhaleSeconds/targetExhaleSeconds; handleBBFirstGate sets breathPhaseRef.current before tutorial guard so BackgroundA/BackgroundB respond during Box Breathing post-tutorial; showTimedText / showSlowingTextC–E / handleSlowingRecordingDone / handleSlowingTextDDone/EDone / showBoxText / transitionBoxText / handleBBFirstGate / handleBBLastGate; showGatesText/showSlowingTextD/showSlowingTextE branch on `shapeRef.current === 'd' || shapeRef.current === 'e'` to pick ambient copy variants; renders a persistent top-center `MODE_LABELS[mode]` caption in the experience-screen overlay for the duration of play (see Modes section), plus a top-left unlabeled Change Target Pace square when `mode === 'slowing'`
  MorphA.jsx                — Shape A: sphere, Fresnel inner glow via onBeforeCompile
  MorphB.jsx                — Shape B: RoundedBox, same Fresnel approach
  MorphC.jsx                — Shape C and D: sphere that dissolves into a particle cloud (metaball-style dissolve shader + two particle systems); reused directly for Option D, no separate Morph file
  MorphE.jsx                — Shape E: 5 concentric torus rings sharing one no-emissive MeshStandardMaterial; per-ring quaternion = slerp(flat exhale pose, fixed-random inhale pose, lv) composed with a bounded sin-wave wobble (amplitude scaled by sin(π·lv), zero at both endpoints) for an organic mid-transition tumble; roughness animated from rv, same convention as other Morphs
  MorphF.jsx                — Shape F (Hot Air Balloon): basket + envelope driven by the right slider, with the cube's 5-breath count inside the envelope
  MorphG.jsx                — Shape G (Paper Airplane): PaperPlane's gray-box plane, flown up/down by breath and sideways by phone side tilt; writes planePosRef
  planeCloudsG.js           — Shape G: planeLimits (the plane's range); bar + ring gates in use (makePlaneCubeGate, ringContainsPlane, hitsPlaneBar, sampleRingSurface, isOffScreenBelow); cloud gates parked (makePlaneGate, hitsPlane, sampleGateSurface, applyPlaneGate)
  GatesG.jsx                — Shape G, Slowing Down/Paced: ring targets (+ bar on Exhale gates) on GatesF's timing, judged against the plane
  GatesBoxBreathingG.jsx    — Shape G, Box Breathing: ring targets (+ bar) on GatesBoxBreathingF's series timing, one side per series
  GroundTiesG.jsx           — Shape G, every mode: tie lines on the ground plane (groundY), scrolling with the gates
  MorphH.jsx                — Shape H (Balloon): gray-box balloon, breath inflates/raises it, side tilt, travel/deflate/bounce overrides from balloonStateRef
  BalloonCourseH.jsx        — Shape H: walls, door and rings, plus the user-gated pace state machine (balloonPaceRef) that the bells/labels/captions follow
  balloonH.js               — Shape H: shared sizes, segment layout and balloonLimits
  MorphJ.jsx                — Shape J (Space Ship): gray-box ship with 3 engines (glow, particles, rocking), drawn from shipStateRef, steered by side tilt while flying
  SpaceshipBayJ.jsx         — Shape J: floor doors, columns, front door, cube targets, and the ship's pace state machine (shipPaceRef)
  spaceshipJ.js             — Shape J: shared sizes, shipLimits, makeCourse
  blowDetector.js           — Blow on the Mic detection: per-frame analysis (noise floor, loose/candidate/strict detectors) and the mic check's profile; pure, so testable offline
  GatesF.jsx                — Shape F, Slowing Down/Paced: cloud gates on GatesB's timing (no ties)
  GatesBoxBreathingF.jsx    — Shape F, Box Breathing: cloud gates on GatesBoxBreathingB's series timing
  LandscapeF.jsx            — Shape F only: copy of LandscapeB (identical behavior), currently not mounted
  breathCountF.jsx          — Shape F only: the balloon's 5-breath count (breathCountB's engine, 7 sets fitted to the envelope's Inhale ellipsoid)
  SideCloudsF.jsx           — Shape F only: side rows of tertiary clouds drifting toward the camera, slid in/out by the slider front to back
  cloudShapeF.js            — Shape F: random cloud shape, cloud material and gate look (pulse, miss, fade-out) shared by the two cloud gate files
  GatesA.jsx                — Shape A: torus exhale/inhale gates with emissive ramp; accepts breathPhaseRef — writes 'exhale' when Gate A crosses z=0, 'inhale' when Gate B crosses z=0; accepts inhaleSecondsRef/exhaleSecondsRef — computeGateBZ() dynamically recomputes the Inhale Gate's spawn z each spawn (ratio 1.5 default, asymmetric during Slowing Down's ramp — see Gate geometry section)
  GatesB.jsx                — Shape B: cube-style gates with same emissive ramp logic; accepts breathPhaseRef — same z=0 crossing callbacks as GatesA; same dynamic computeGateBZ()/inhaleSecondsRef/exhaleSecondsRef mechanism as GatesA
  GatesC.jsx                — Shape C: alternating inhale torus (z=-20) + exhale sphere (z=-30, r=0.25, 0.25 alpha, emissive pulse at z=0); 3 slots each; accepts breathPhaseRef — writes 'inhale' when torus crosses z=0, 'exhale' when sphere crosses z=0; accepts inhaleSecondsRef/exhaleSecondsRef — computeExhaleSpawnZ() dynamically recomputes the exhale sphere's spawn z (ratio 1.5 default, asymmetric during Slowing Down's ramp)
  GatesHeadless.jsx         — Shape D, Paced Breathing/Slowing Down only: same pooled inhale/exhale timing simulation as GatesC, stripped of all meshes/materials/ties; renders null; writes breathPhaseRef on the same crossings; same dynamic computeExhaleSpawnZ()/inhaleSecondsRef/exhaleSecondsRef mechanism as GatesC. Box Breathing uses GatesBoxBreathingC instead (see below) — no headless variant needed there.
  GatesHeadlessE.jsx        — Shape E, Paced Breathing/Slowing Down: independent copy of GatesHeadless.jsx (own SPAWN_Z/EXHALE_SPAWN_Z/pool constants) — same pooled timing simulation, renders null, writes breathPhaseRef; same dynamic computeExhaleSpawnZ()/inhaleSecondsRef/exhaleSecondsRef mechanism. Unlike Option D, Option E also stays headless in Box Breathing (see GatesBoxBreathingHeadlessE.jsx below) — there is no visible-gates file for Shape E at all.
  GatesBoxBreathingA.jsx    — Box Breathing, Shape A: torus rings (inhale=narrow tall, exhale=wide flat), POOL_SIZE=28, SPAWN_Z=−6; onFirstGate/onLastGate pre-triggered at z=−speed×2
  GatesBoxBreathingB.jsx    — Box Breathing, Shape B: cube-style gates, same pool/spawn/callback pattern as A
  GatesBoxBreathingC.jsx    — Box Breathing, Shape C and D: inhale torus + exhale sphere, same pattern; no road ties in any box breathing file; Shape D pairs this with BackgroundA also rendering
  PaceRingsD.jsx            — Shape D shared pace-ring hook (usePaceRings): Pulse/Hold ring, Pulse/Hold Exhale ring, count rings; used by GatesBoxBreathingD and SlowingDownPaceRingsD
  SlowingDownPaceRingsD.jsx — Slowing Down + Shape D: drives usePaceRings from breathPhaseRef/computePhaseDurations
  GatesBoxBreathingHeadlessE.jsx — Box Breathing, Shape E: mirrors GatesBoxBreathingC's exact spawnSeries/onFirstGate/onLastGate timing (so App.jsx's tutorial-text/breathPhaseRef wiring works unmodified) but renders no meshes; additionally writes holdFlareRef.current (0-2 emissive value, calcEmissive ramp re-centered on the in-flight series' isFirst-slot z) each frame for StarFieldE to consume
  Sliders.jsx               — Vertical slider layout: DOM overlay sliders (top 63% to 16px from bottom), fill indicator
  SlidersDiagonal.jsx       — Diagonal slider layout: two curved "hook" tracks rendered as SVG circular-arc paths (via diagonalCurveGeometry.js), bottom-anchored at `bottom: 16`; thumb positioned via `pointAtArcFrac` (arc-length interpolation along the curve) and fill indicator via `strokeDasharray`; same value semantics/props as Sliders.jsx, drop-in swap based on sliderLayout
  diagonalCurveGeometry.js — shared curve geometry for the Diagonal slider layout, single source of truth for both SlidersDiagonal.jsx (rendering) and useTouchSlider.js (touch hit-testing): circular-arc endpoints (`P0_FRAC`/`P2_FRAC`, left-side fractions of a `CURVE_BOX_W × CURVE_BOX_H` box, right side mirrors x→1−x) plus `ARC_DEGREES` (how far the arc turns; `getArc` finds the circle, center on the outer/lower side); `sampleCurve`/`SAMPLE_CACHE` precompute arc-length-parameterized points per side; `projectToCurve` (nearest-point + local segment projection) converts a raw drag point to an arc-length fraction for input; `pointAtArcFrac` converts a fraction back to a point for thumb placement; `getPathD`/`getCurveLength` feed the SVG path and stroke-dash fill
  useTouchSlider.js         — touch hook with identifier tracking (multi-touch); 3rd param `orientation` ('vertical' default, 'diagonal-left', 'diagonal-right') controls how a drag point maps to a ratio — single-axis clientY/rect.top/rect.height for vertical, curve-projection via diagonalCurveGeometry.js's `projectToCurve` for the two diagonal orientations
  StartButton.jsx           — the round Start button (Home at size 110, option screens at 72)
  OptionsNav.jsx            — Art Options / Control Options bottom row: Home: Mode Options, small Start + mode caption, the other option screen
  SelectModeScreen.jsx      — app's home screen (bold pink "HOME" title; all-caps "MODES" subheading styled like Art Options' title, its bottom margin tuned so it sits 12px above the first card; 3 selectable mode cards labeled via MODE_LABELS: Tutorial, Box Breathing, Slowing Down (Own Pace and Paced Breathing hidden but still implemented); selectedMode/onSelectModeChange are props lifted from App.jsx (localStorage-backed, persists the selection across navigation), not local state; no top-left button); bottom-center stacked group — a large circular pink-outlined Start button (translucent pink fill, brightens on press, launches selected mode) above the side-by-side Art Options / Control Options pills (→ Art Options / Control Options screens) button
  SliderLayoutsScreen.jsx   — Vertical/Diagonal selectable cards (persisted via sliderLayout), single Home nav button (bottom center)
  BreathPaceOptionsScreen.jsx — Breath Pace Options screen: 3 selectable cards sourced from TARGET_PACES (breathPace.js), persisted via targetPace; single "Back"-labeled nav button (bottom center, prop still named onHome) returning to the `'experience'` screen (not selectMode, since reached mid-Slowing-Down-session)
  PersonalizeScreen.jsx     — Art Options screen (on-screen title "ART OPTIONS", screen id stays 'personalize'); shape selection shown directly as a scrollable card list (height 380, overflowY auto), 7 cards: B, D, F, G, H, J, I (see screens.md); Options A/C/E have no card; single Home nav button at bottom
  BackgroundA.jsx           — 30 scattered RoundedBox cubes (args [0.5,0.5,0.5], gateColor/emissiveColor); positions randomized in useMemo (X∈[−8,8], Y∈[−10,−4], Z∈[−30,5]); animates between State A (opacity=0, emissiveIntensity=0, Y−5) and State B (opacity=0.1, emissiveIntensity=1, spawn Y) via direction-aware progress (exhaleSecondsRef seconds toward State B, inhaleSecondsRef seconds toward State A, falling back to spawnIntervalRef/2 for both when either ref is null) with smoothstep easing; driven by breathPhaseRef+gatesEnabledRef; props: gateColor, emissiveColor, breathPhaseRef, gatesEnabledRef, spawnIntervalRef, inhaleSecondsRef, exhaleSecondsRef; rendered only when shapeOption === 'd', in every mode including Box Breathing
  BackgroundB.jsx           — 5 concentric torus rings (unrotated, camera-facing), sharing one no-emissive material (gateColor, opacity 0.6); whole-group scale (not per-mesh opacity/Y) lerps 0→1 via the same progressRef/target/direction-aware-halfInterval/smoothstep pattern as BackgroundA; props: gateColor, breathPhaseRef, gatesEnabledRef, spawnIntervalRef, inhaleSecondsRef, exhaleSecondsRef; rendered only when shapeOption === 'e', in every mode including Box Breathing
  StarFieldE.jsx            — Box Breathing + Shape E only: ~50 tiny always-visible spheres scattered X∈[−8,8]/Y∈[−3,6]/Z∈[−30,5]; one shared material (gateColor base, emissiveColor emissive) whose emissiveIntensity is set each frame from holdFlareRef.current (0-2); props: gateColor, emissiveColor, holdFlareRef
  LandscapeB.jsx            — Shape B only: landscape shapes (spheres / rounded cubes / tetrahedrons, one kind per 5-breath group via landscapeIndexRef) flowing past on both sides of the road; see Landscape (Shape B) section
  CameraVerticalShift.jsx   — rendered only when shapeOption === 'd'; null-rendering helper that applies a shift-lens vertical crop to the active camera via setViewOffset (EXTRA_HEIGHT_FRACTION 0.6, SHIFT_FRACTION 0.65), cleaning up with clearViewOffset on unmount. Per-shape camera *position/fov* lives in App.jsx's CAMERA_BY_SHAPE map, not here
  TutorialText.jsx          — fade-in/out tutorial overlay (top of screen); `whiteSpace: 'pre-line'` on `<p>` so `\n` in copy strings renders as line breaks; optional `opacity` (0-1 number, overrides `visible` for continuous slider-driven fades) and `fadeMs` (default 2000) props support the Diagonal layout's Text A1/A2/B1/B2 sequence
  BreathLengthControl.jsx   — top-left slider + value + label for adjusting breath interval in Paced Breathing only (no longer used by Slowing Down); fades in 2s after Text D
  SlowingDownController.jsx — breath cycle detection + dynamic gate interval; phases: idle→warmup(3)→recording(2)→gates; captures lastMaxTimeRef (inhale peak time) for gate phase-locking; calls onGatesReady when Initial Pace is set, onTextDone/onTextEDone after respective post-gate cycle counts; in the `gates` phase, every frame interpolates inhaleSecondsRef/exhaleSecondsRef from avgBreathRef/2 toward the targetInhaleSeconds/targetExhaleSeconds props (from App.jsx's targetPaceInfo) over RAMP_SECONDS, and sets spawnIntervalRef to their sum — idempotent past t=1, no "ramp done" callback since nothing fires after the ramp anymore
  useWakeLock.js            — Screen Wake Lock while a session runs (App: `useWakeLock(!!mode)`, every control), so hands-free controls don't let the phone sleep; re-requested on `visibilitychange` and any `pointerup`, released on Home. No-op where the API is missing (iOS < 16.4)
  palettes.js               — PALETTES object: tertiaryColor, primaryColor, secondaryColor, background, textColor, headerColor, subheaderColor — the naming convention every future palette should follow (see Color Palettes section); 3 entries defined — `teal` (active), `a` and `b` (both unreachable, kept for a future Color Options screen)
  breathPace.js             — TARGET_PACES ('6-6'/'5-5'/'4-6' → {inhale, exhale, label}) and DEFAULT_TARGET_PACE ('6-6'); single source of truth for both Slowing Down's ramp targets and Breath Pace Options' card labels, so the numbers and their displayed text can't drift out of sync
  copy.js                   — MODE_LABELS (mode id → display name, e.g. basic → "Breathe at Your Own Pace"; shared by SelectModeScreen's mode cards and App.jsx's top-center in-play label) plus tutorial text strings (TEXT_A, TEXT_B, TEXT_A1_DIAGONAL / TEXT_A2_DIAGONAL / TEXT_B1_DIAGONAL / TEXT_B2_DIAGONAL, TEXTS.gatesTimed / TEXTS.gatesTimedD / TEXTS.gatesSlowing / TEXTS.slowingTextD / TEXTS.slowingTextE / TEXTS.boxInhale / TEXTS.boxHold / TEXTS.boxExhale, plus Shape Option D's ambient variants TEXTS.gatesTimedAmbient / TEXTS.gatesTimedDAmbient / TEXTS.slowingTextDAmbient / TEXTS.slowingTextEAmbient — edit here to change wording); TEXT_A and TEXT_B use `\n` for multi-line layout; TEXTS.slowingTextF/slowingTextG were removed along with Slowing Down's post-ramp text (see Modes section)
  Track.jsx                 — wave track lines (not currently rendered, kept for reference)
  Morph.jsx                 — legacy, superseded by MorphA/MorphB
  Gates.jsx                 — legacy, superseded by GatesA/GatesB
  main.jsx                  — entry point
```
