# Tutorial text rules

_Moved out of CLAUDE.md on 2026-11-10. Detail reference: read when working on this area._

## Tutorial text rules
- **Mode explanation (first):** at the start of Own Pace only (Box Breathing and Slowing Down open with Tutorial-style screens instead; `MODE_INTRO` in `copy.js`, keyed by mode id), an explanation of the mode and its tutorial shows for `MODE_INTRO_MS` 10 s near the top of the screen, starting two blank caption lines below the mode name plus two more blank lines at its own size (`TutorialText` `topPx` = `MODE_CAPTION_TOP` + (label lines + 2) × `MODE_CAPTION_LINE_PX` 16 + `INTRO_EXTRA_LINES` 2 × 30 px × 1.2; all later tutorial text stays at its usual spot), then fades out over `MODE_INTRO_FADE_OUT_MS` 4 s before the tutorial begins (`beginTutorial` in `handleSelectMode`: Text A, or Diagonal A1, which fades in over `A1_FADE_IN_MS` 2 s in stage `'A1-appear'` — opacity = eased ramp × the slider-bound `1 − breath`, so touching a slider meanwhile doesn't pop it — then hands off to stage `'A1'`).
- **Blank-background start:** a cover in the live background color hides the scene, and the sliders layer sits at opacity 0, untouchable (`sceneRevealed`/`slidersTouchable`, reset on every Start/Restart). This lasts through the mode explanation, so testers read before they can play with the sliders. When the tutorial begins (`beginTutorial`), `revealScene` fades the cover out and the sliders in over `SCENE_REVEAL_MS` 3 s, at the same time as Text A1 (or Text A) fades in; the sliders are touchable from the moment the fade starts. The mode caption and Home/Restart stay visible throughout. The experience wrapper has `touch-action: none`, and a document `gesturestart`/`gesturechange` blocker (plus `maximum-scale=1` in `index.html`) stops iOS pinch-zoom, so a stray touch never zooms or pans the page.
- **Font sizes** (`TutorialText` `size` prop): mode explanation and Tutorial Part screens `TEXT_SIZE_INTRO` 24 px; paced captions (Inhale/Hold/Exhale, Box and Slowing Down) `TEXT_SIZE_CAPTION` 60 px; everything else `TEXT_SIZE_TUTORIAL` 30 px, raised `TUTORIAL_TEXT_LIFT_PX` 72 px (2 lines) above the default spot via `TutorialText` `liftPx` (all modes; top-of-screen texts don't move). Box's 60 px Inhale/Exhale captions (and the Hold line under them) are raised one caption line, `TEXT_SIZE_CAPTION` × 1.2 = 72 px. Text above 20 px (all of it now) gets a 92vw column, 16 px side padding and line height 1.2.
  - While it shows, `stageRef`/`diagStageRef` sit at `'intro'` so slider movement doesn't advance the tutorial, and `introActiveRef` blocks idle re-show.
  - Its timer is `introTimerRef`, cleared on Restart and Home.
  - Paced Breathing (hidden) has no explanation.
Universal A/B sequence, then mode-specific C/D (defined in `src/copy.js`). **This A/B sequence is Vertical-slider-layout only** — the Diagonal layout uses a completely different Text A1/A2/B1/B2 sequence instead (see below); both hand off to the same mode-specific Text C onward.

- **Text A** (Vertical layout only) — "Move the sliders / in opposite directions / with your thumbs" (3 lines via `\n`). Shown at mode start. Stays visible until the **right slider** has completed **2 full up+down oscillations** (4 direction reversals detected with an 8% deadband, tracked in `rightStrokeCountRef`), then fades out over 2 seconds. If the user never moves the right slider, Text A stays up indefinitely.
- **Text B** (Vertical layout only) — "The transforming object is named Morph. / Sync your breathing to Morph." (line break after "Morph." via `\n`). Fades in once Text A fades out. Stays visible until the right slider completes **3 more full oscillations** (6 reversals, same deadband logic, counters reset when B begins), then fades out over 2 seconds.
- **Diagonal layout Text A1/A2/B1/B2** (replaces Text A/B entirely for `sliderLayout === 'diagonal'`; driven by `updateDiagonalSequence` in `App.jsx`, called from `setLeft`, using `diagStageRef` as the stage cursor):
  - **Text A1** — "Inhale and move the sliders up." Shown immediately at mode start, opacity bound continuously to `1 - lv` (left slider) via a numeric `opacity` prop on `TutorialText` — no fixed timer, it fades exactly in step with the left slider moving from bottom (0) toward top (1). When `lv >= 1 - DIAG_EDGE_THRESHOLD` (0.98), Text A1 is effectively invisible and Text A2 begins. **A1/A2 run `DIAG_ROUNDS` 3 times** (`diagRoundRef`), in the order round 1 → B1 → rounds 2–3 → B2 → B3: after round 1, B1 shows; B1's fade-out starts round 2 (`showA1Again`: A1 fades back in over 1 s, stage `'A1-reappear'`, then tracks `1 - lv`); after round 3, B2 shows.
  - **Text A2** — "Good! Exhale and move the sliders down." Fades in over 1 second (`DIAG_FADE_IN_MS`) from 0, then tracks continuously: opacity = `lv`, fading out 1→0 as the user drags back down. When `lv <= DIAG_EDGE_THRESHOLD` (0.02), Text A2 is effectively invisible and Text B1 begins.
  - **Text B1** — "Moving fingers with your breath is the core interaction in this app." Fades in over 1 second. Once fully visible, stays up for **1 full breath cycle** — detected as 2 left-slider direction reversals ("strokes", `DIAG_CYCLE_STROKES = 2`, same 8%-deadband algorithm as the Vertical layout's oscillation counter, tracked in `diagDirectionRef`/`diagExtremeRef`/`diagReversalCountRef`) — then fades out over 2 seconds (`DIAG_FADE_OUT_MS`).
  - **Text B2** — "Notice how your breathing controls the art and sound." Fades in over 1 second once Text B1 has fully faded out. Stays up for 1 more full breath cycle (same 2-stroke detection, counters reset), then fades out over 2 seconds.
  - **Text B3** (`TEXT_B3`, both layouts; Vertical shows it after Text B) — "Now the art will change with each breath." Same timing as B2 (`showDiagonalStep`). `setRight` keeps feeding `updateDiagonalSequence` during the B3 stages even in the Vertical layout.
  - After Text B3 fully fades out (`finishDiagonalSequence`), `diagStageRef.current` is set to `'done'`, counting and the count tutorial start, and — exactly like the Vertical layout's Text B → Text C handoff — `pendingGatesFnRef.current` (if set) is consumed and invoked, starting the mode-specific Text C onward. Basic mode leaves `pendingGatesFnRef` null, so the tutorial simply ends, same as Vertical.
  - The 10-second idle-reshow effect is suppressed while this sequence is in progress (`sliderLayout === 'diagonal' && diagStageRef.current !== 'done'`) since the continuous-opacity phases already reflect live slider position rather than a hidden/shown boolean; it resumes normally once the sequence reaches `'done'`, covering Text C onward exactly as it does for Vertical.
  - `TutorialText.jsx` accepts optional `opacity` (0–1 number) and `fadeMs` (number, default 2000) props: when `opacity` is a number it overrides the `visible` boolean entirely (used for A1/A2's continuous fades), otherwise `visible` + a CSS `opacity {fadeMs}ms ease` transition is used (used for A2/B1/B2's fixed fade-in/fade-out steps, and unchanged for all of Vertical's Text A/B onward).
- **5-count tutorial** (Own Pace only; both skins): driven by the Morph counters' `onBreathCountEvent(type, cycle, n)`. `'breath'` fires once as piece n (1-5) of count cycle `cycle` (0-based) starts to appear; `'cycleDone'` fires as a cycle's pieces go away. `handleBreathCountEvent` in App.jsx (`countTutorialRef`) shows each text on its breath and fades it out on the next one. Every change goes through `fadeToText`: the visible text fades out over `COUNT_FADE_MS` 1 s (or a running fade-out finishes, `textFadeOutEndRef`), then the new text fades in over 1 s — words never swap while visible. Idle re-show also waits for a running fade-out.
  - **Cycle 1:** breath 1 "Notice how the art changed." (`countEachBreath`), breath 3 "These changes help count breaths." (`countColors`), breath 5 "After 5 breaths, the counting resets. The colors and sounds will change." (`countResets`); breaths 2 and 4 fade out.
  - **Cycle 2, breath 1 (every mode):** "This is a new 5-breath cycle." (`countNewCycle`). Own Pace's tutorial ends at breath 2 (fade out).
- **Text C (Paced Breathing)** — "Fit Morph through the oncoming targets to pace your breath." Queued via `pendingGatesFnRef` thunk when Paced Breathing mode starts. Fires after Text B finishes (or immediately if A/B already done). Enables gates. Fades out after **2 breath cycles** (`spawnIntervalRef × 2` seconds, captured at Text C fire time).
- **Text D (Paced Breathing)** — "Adjust the pace of the targets with the slider on the left." Fades in 2 seconds after Text C fades (FADE_TRANSITION_MS gap). `BreathLengthControl` fades in 2 seconds after Text D appears. Fades out after **3 breath cycles** (`spawnIntervalRef × 3` seconds).
- **Shape Options D/E ambient copy**: since Options D and E have no visible targets, `showGatesText` (Paced Breathing Text C/D) and `showSlowingTextD`/`showSlowingTextE` (Slowing Down Text D/E) branch on `shapeRef.current === 'd' || shapeRef.current === 'e'` in `App.jsx` and substitute `TEXTS.gatesTimedAmbient` / `TEXTS.gatesTimedDAmbient` / `TEXTS.slowingTextDAmbient` / `TEXTS.slowingTextEAmbient` (in `copy.js`), which reference the background's rhythm instead of targets — Option E reuses these verbatim (no dedicated ring-specific copy yet). All other tutorial text (A, B, Slowing Down C/D/E, Box Breathing C–F) is shape-agnostic and unchanged for Options D/E.
- **Text C (Slowing Down)** — "Breathe at your own pace for a few breaths." Queued via `pendingGatesFnRef` thunk when Slowing Down mode starts. Fires after Text B finishes. Sets `recordingEnabledRef.current = true` to start the warmup/recording flow in `SlowingDownController`. No auto-dismiss timer — stays until `SlowingDownController` calls `onGatesReady()` (recording complete), which triggers Text C fade-out.
- **Text D (Slowing Down only)** — "Good Job! The oncoming targets will begin at your pace and slow down over the next minute." (Options D/E: "You will soon see art animate at the rate you recorded." — B2-style timing, followed by Text E; see Slowing Down → D/E hand-off) Shown 2 seconds after Text C fades out (after FADE_TRANSITION_MS gap). No auto-dismiss timer — stays until `SlowingDownController` calls `onTextDone()` after 3 post-gate breath cycles, then fades.
- **Text E (Slowing Down only)** — "Keep Morph aligned with the targets to slow down your breathing." (Options D/E: "Keep your breathing in sync with the art as it slows down." — shown right after Text D with the same B2-style timing, before the art starts; the idle re-show text from then on) Shown 2 seconds after Text D fades. No auto-dismiss timer — stays until `SlowingDownController` calls `onTextEDone()` after 4 more post-gate breath cycles, then fades. Nothing further appears after Text E — Slowing Down no longer has a Text F/G or post-ramp slider (see Slowing Down section).
- **Text C (Box Breathing)** — "Inhale slowly". Queued via `pendingGatesFnRef` thunk. Fires after Text B, simultaneously enables gates and shows this text via `showBoxText`. No fade gap — appears immediately using `showBoxText` (not `transitionBoxText`).
- **Text D (Box Breathing)** — "Hold". Pre-triggered when the first gate of an inhale series reaches z=−speed×2; `transitionBoxText` hides current text then shows "Hold" after `BB_TEXT_LEAD_MS=1600ms` — text starts at gate z≈−0.6, coinciding with the steep emissive ramp.
- **Text E (Box Breathing)** — "Exhale slowly". Pre-triggered when the last gate of an inhale series reaches z=−speed×2.
- **Text F (Box Breathing)** — "Hold". Pre-triggered when the last gate of an exhale series reaches z=−speed×2. After 2 complete cycles (`bbCycleRef` reaches 2), `bbTutorialActiveRef` is set false and text hides permanently.
- **Idle re-show**: if the sliders are still for 10 seconds, the most recently shown text reappears and stays until 2 seconds after the sliders start moving again, then fades out (does not restart the sequence). Depending on mode this is one of A, B, C, D, E (Slowing Down's last possible text) or A, B, C, D, E, F (Box Breathing's own, unrelated Text F/Hold — not to be confused with Slowing Down's now-removed Text F).
- Fade transitions take 2 seconds (`FADE_TRANSITION_MS = 2000` in `App.jsx`, must match the CSS transition in `TutorialText.jsx`). Box Breathing uses `BB_TEXT_LEAD_MS = 1600` instead for its `transitionBoxText` calls.
- `TutorialText.jsx` is positioned at `top: 'calc(44% + 24px)'` with `transform: 'translateY(-50%)'` — in front of the Morph's lower third — with `zIndex: 100` so it always draws above the canvas, sliders and nav. Letters get an outline in the live background color (`--live-bg-color`, set by `PaletteLerpDriver`) via an 8-way `text-shadow` ring plus a soft halo, so they read over light and dark art. Uses `whiteSpace: 'pre-line'` so `\n` in copy strings renders as actual line breaks.
